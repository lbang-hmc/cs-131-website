## Think About Programming-Language Design

In this part, you'll reflect on how programming languages are designed by comparing them to *spoken* languages.

First, [choose a random number between 1 and 10](https://www.google.com/search?q=random+number+between+1+and+10). Map it to one of these 10 most-common spoken languages by number of native speakers, [according to Wikipedia](https://en.wikipedia.org/wiki/List_of_languages_by_number_of_native_speakers):

1. Mandarin Chinese
2. Spanish
3. English
4. Hindi
5. Bengali
6. Portuguese
7. Russian
8. Japanese
9. Western Punjabi
10. Marathi

**Your task:** describe your language's:

- **Character set** — the set of valid characters used to write it. If the character set has a name, you can just use the name.
- **Directionality** — is it written left-to-right, right-to-left, top-to-bottom?

Now, [choose a *different* random number between 1 and 10](https://www.google.com/search?q=random+number+between+1+and+10). Map it to one of these 10 most-used programming languages, [according to the TIOBE index](https://www.tiobe.com/tiobe-index/):

1. C
2. Java
3. Python
4. C++
5. C#
6. Visual Basic
7. JavaScript
8. PHP
9. R
10. Groovy

**Your task:** describe your language's:

- **Character set** — a human-language summary is fine (e.g. "the letters of the English language, plus some operators").
- **Directionality**.
- **Keywords** (also called *reserved words*) — you can usually find these by searching `<language name> keywords`.

## Where to Go From Here

If the themes of this assignment grabbed you, here's more to explore:

- [**Access Computing**](https://www.washington.edu/accesscomputing/) — this assignment touched on how one's spoken language can intersect with programming-language design, and who that leaves out. Access Computing focuses on a different form of accessibility: increasing participation of people with disabilities in computing fields.
- The Swift programming language has some [great](https://www.apple.com/education/k12/teaching-code/) [materials](https://developer.apple.com/videos/play/wwdc2020/10681/) for programming games designed for people who are blind or have limited vision, and for sighted people alike.
- A couple of books behind some of the historical material you've seen in this course:
    - [*The Thrilling Adventures of Lovelace and Babbage*](https://www.penguinrandomhouse.com/books/223672/the-thrilling-adventures-of-lovelace-and-babbage-by-sydney-padua/) by Sydney Padua
    - [*Logicomix*](https://en.wikipedia.org/wiki/Logicomix)
- A talk called [**"The Programming Language Called Classical Chinese"**](https://www.youtube.com/watch?v=vBhg2p8aAQ0).
- A talk called [**"Inventing on Principle"**](http://worrydream.com/#!/InventingOnPrinciple), about how our programming tools shape our programming behavior. One of our favorites.
