# Labs

Labs are in-class, hands-on sessions — mostly working directly in `ghci`, with the occasional file to edit. They're meant to be done live, ideally with a partner or grutor nearby to ask questions. To start:

- [**Lab 2: GHCi Basics**](lab02.md) — evaluating expressions, `map`/`filter`/`reverse`/`show`/`sort`, and loading a file into `ghci`.
- [**Lab 3: Tuples, Stacks, and Currying**](lab03.md) — pairs, comparing multiple correct implementations of stack operations, and currying/uncurrying.
- [**Lab 4: Boolean Expressions**](lab04.md) — completing an evaluator and pretty-printer for a small boolean-expression datatype.
