# Course Modules

An overview of course modules will be posted here as they're published. To start:

- [**01.1: Welcome to Programming Languages**](01.1-welcome-to-programming-languages.md) — the history of programming languages, what CS 131 is (and isn't), and the three big ideas that run through the whole course.
- [**02.1: Introduction to Haskell and Functional Programming**](02.1-introduction-to-haskell-and-functional-programming.md) — your first Haskell: values, types, functions, bindings, pattern matching, and abstraction.
- [**02.2: Functions = Values**](02.2-functions-as-values.md) — purity, laziness, operator precedence, currying, and function composition.
- [**03.1: Lists, Tuples, Pattern Matching, and Parameterized Types**](03.1-lists-tuples-pattern-matching-and-parameterized-types.md) — building and taking apart lists and tuples, `map` and `filter`, and your first parameterized types.
- [**03.2: Haskell Data Types, Pattern Matching, and Type Classes**](03.2-haskell-data-types-pattern-matching-and-type-classes.md) — defining your own data types, OOP vs. functional thinking, and type classes.
- [**04.1: Code as Data, Evaluating Expressions**](04.1-code-as-data-evaluating-expressions.md) — expressions vs. statements, syntax vs. semantics, and representing and evaluating expressions as data.
- [**04.2: Representing Functions**](04.2-representing-functions.md) — representing function definitions and application as data, substitution, and call-by-name vs. call-by-value.
